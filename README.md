# Medieval Online RP Thailand

เว็บไซต์รวมหน้าเดิมไว้ในเว็บไซต์เดียว พร้อมเมนูด้านซ้าย และรองรับ GitHub Pages

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ไปที่ repository
3. เปิด **Settings → Pages**
4. เลือก **Deploy from a branch**, branch `main` และโฟลเดอร์ `/(root)` แล้วกด Save

เว็บไซต์จะเปิดจาก URL ที่ GitHub แสดงในหน้า Pages
